# 技术插图规范

## 格式与来源

| 图类 | 源文件 | 插入/交付 |
|---|---|---|
| 框图、流程图、状态机、时钟树 | 结构化 JSON、SVG 或用户可编辑源 | SVG 优先，PNG 作兼容版本 |
| 寄存器位图 | 经核对的寄存器模型 | SVG 和 PNG |
| 时序图 | 明确的信号序列、有效边沿及时间约束 | SVG，保留绘图数据 |
| 封装引脚图 | IOMUX、封装尺寸及方向资料 | SVG，核对 Pin 1、顶/底视图和 EP |
| 测试曲线 | 原始 CSV/XLSX 和绘图程序 | SVG/PDF、PNG；注明条件与单位 |
| 截图/实物照片 | 原始 PNG/JPEG | 原图加文档边框；必要裁剪保留测量条件 |

技术连接关系和文字不得依靠生成式图像模型猜绘。矢量重绘依据原图核对每个端口、方向、极性和单位。截图放大不等于恢复细节；禁止补造测量值或消除异常波形。

## 默认样式

- 白底、黑色 0.5–0.75 pt 外框；同一手册内部连线/箭头规格一致。
- 图片水平居中，保留纵横比，正文宽度内排版；不把原始图拉伸成固定高宽。
- 以最终印刷尺寸衡量字体，建议图中文字不小于 8–9 pt。需要更小文字时拆图，避免单纯压缩。
- 彩色图用黑白也能区分，图例不要仅靠颜色。单位、正负号、下标、信号有效电平一致。
- 栅格线图以最终尺寸约 300 dpi 或更高生成；低分辨率原截图报告其局限，不伪称重绘高清。
- 图题位于图下，表题位于表上；两者均有编号、清晰名称和自动目录。
- 替代文本描述图的用途；原始图片单独保留，优先在 DOCX 图片形状上加边框。

## 随附 figure_tools.py

`diagram` JSON 有 `width/height/items`。item 支持 `rect`(x,y,w,h)、`line`(x1,y1,x2,y2,arrow可选)、`text`(x,y,text,size可选)。文字中心锚定，不自动换行；用 `\n` 明确换行并检查最终效果。坐标为画布单位，源文件须可编辑。未支持类型报错，不默默遗漏。

SVG 和 PNG 由同一组几何图元生成。默认输出比例 3 px/画布单位；Word 使用正文宽度展示，实际有效 DPI 仍须检查。PNG 字体选择顺序为显式字体路径、Windows 微软雅黑/宋体、Linux Noto CJK；无中文字体则失败，不能交付方框字。

示例只有总线框图和寄存器位图。时序图、封装图和曲线的特定语义验证尚需实现；本 skill 提供规范，不宣称它们已有完整自动生成器。
